# Hướng dẫn nộp bài Cars Dealership Capstone

## 1. Upload project lên GitHub

Tạo repository public tên ví dụ:

cars-dealership-capstone

Sau đó dùng Git Bash trong thư mục project:

```bash
git init
git add .
git commit -m "Add cars dealership capstone submission"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/cars-dealership-capstone.git
git push -u origin main
```

Nếu remote bị sai:

```bash
git remote remove origin
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/cars-dealership-capstone.git
git push -u origin main
```
