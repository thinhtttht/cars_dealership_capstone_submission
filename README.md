# Cars Dealership Capstone Project

## Repository name
cars_dealership_capstone_submission

## Project name
Cars Dealership

## Project description
This full-stack capstone project is a responsive Cars Dealership web application. It allows users to view dealership branches, filter dealers by state, view dealer details, register and log in, submit reviews, and see sentiment analysis results for dealership reviews.

## Features
- View all dealers
- Filter dealers by state
- View dealer details and reviews
- User registration and authentication
- Submit dealership reviews
- Sentiment analysis for review text
- Static About Us and Contact Us pages
- CI/CD workflow with GitHub Actions
- Deployment-ready Django/React application

## Technologies used
- React
- Django
- Flask
- Node.js
- MongoDB
- SQLite
- Docker
- Kubernetes
- IBM Cloud Code Engine
- GitHub Actions
